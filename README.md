# XPlist-Edit — Apple Silicon edition

An ARM64 adaptation of [ic005k/Xplist](https://github.com/ic005k/Xplist), preserving its Qt Widgets interface and XML / binary plist editing features. Edition: **1.2.47-arm64.1**.

See [the build and installation guide](README-arm64.md) and [validation results](VALIDATION-arm64.md). The current locally built package requires **macOS 27.0 or later** and uses ad-hoc signing. Upstream automatic updates are disabled for this edition. Generated application bundles and disk images are excluded from this source repository.

The original project description and credits follow.

## Xplist -- Open source cross-platform lightweight plist file editor

This is a lightweight plist editor with rich features. The file format supports XML and binary plist files under all platforms.
